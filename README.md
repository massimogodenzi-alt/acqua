# Treblex Acqua Lazio — prototipo

Prototipo per cercare PDF Acqualatina e leggere righe che contengono parametri dell'acqua. **Non fornisce valori certificati e non copre ancora tutti i comuni del Lazio.**

Distribuzione su Render: New > Blueprint > collega questo repository. Il file render.yaml definisce il servizio Python. Verificare che la fonte esterna sia raggiungibile e che i risultati corrispondano alla zona corretta.
